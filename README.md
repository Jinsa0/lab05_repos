## Умова

Дано дійсні числа s, t. Обчислити значення виразу

    z = ( f(1, t + s, s) + f(t, s·t, 1) ) / ( 1 + f²(s, 1, t) ),

де

    f(a, b, c) = a·sin(b) + b·sin(a) + c².

## Допоміжна функція f

```cpp
double f(const double a, const double b, const double c)
{
    return a * sin(b) + b * sin(a) + c * c;
}
```

Функція `f` обчислює значення виразу `a·sin(b) + b·sin(a) + c²`.
Параметри `a`, `b`, `c` передаються як параметри-значення. Результат
повертається через `return`. У програмі функція викликається тричі
з різними аргументами.

## Unit-тести

Тести перевіряють функцію `f` на нульових, простих, від'ємних та
однакових значеннях аргументів. Для дійсних чисел використовується
допустима похибка `1e-9`.

Запуск: Visual Studio → Test → Run All Tests.
